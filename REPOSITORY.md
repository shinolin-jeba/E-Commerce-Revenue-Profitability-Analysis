## 🎯 Project Purpose

The repository is organized to clearly separate the different stages of the data analytics project:

**Raw Data → Data Cleaning → Data Modeling → Analysis → Visualization → Business Insights**

This structure makes the project easier to understand, maintain, and present as part of a **Data Analytics / Power BI portfolio**.
